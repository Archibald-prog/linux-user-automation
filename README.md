# Linux User Automation Tools 🐧👥

Набор системных скриптов на Bash для автоматизации пакетного управления учетными записями пользователей в операционных системах семейства Linux (Ubuntu/Debian). 

Утилиты автоматизируют рутинные операции сисадмина по развертыванию тестовых сред или онбордингу сотрудников, исключая ручной ввод команд.

## 🛠️ Функционал
* `create_users.sh` — считывает логины из конфигурационного файла, автоматически создает пользователей в системе, генерирует домашние директории и задает базовые параметры безопасности.
* `delete_users.sh` — производит безопасное пакетное удаление заданных учетных записей с корректной очисткой связанных с ними домашних каталогов.
* `users.txt` — конфигурационный файл-шаблон, содержащий список целевых логинов (каждое имя с новой строки).

## 🚀 Инструкция по запуску
Поскольку скрипты выполняют административные действия (модификация файлов `/etc/passwd` и `/etc/shadow`), запуск утилит должен осуществляться строго с правами суперпользователя (**sudo**):

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Archibald-prog/linux-user-automation.git
cd linux-user-automation

# 2. Сделать скрипты исполняемыми
chmod +x create_users.sh delete_users.sh

# 3. Запуск автоматического создания пользователей
sudo ./create_users.sh

# 4. Запуск автоматического пакетного удаления
sudo ./delete_users.sh
```

## ⚙️ Системные требования
* Операционная система: Ubuntu / Debian / CentOS
* Интерпретатор: Bash v4+
* Права доступа: root / sudo-привилегии
